# Pollify - Frontend Client

This is the frontend client for **Pollify**, built using **React 19**, **Vite**, and **Tailwind CSS v4**.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The frontend will run on `http://localhost:5173`.

## Environment Variables

Create `.env` in this directory:
```env
VITE_API_URL=http://localhost:5000
```
For production deployment, set `VITE_API_URL` to your production backend URL (e.g. `https://pollify-a6pb.onrender.com`).

For full project documentation and live links, see the [Root README](../README.md).
